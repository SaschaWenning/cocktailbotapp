CocktailBot Software-Version 2.5 – Update-Prüfung

VERSIONIERUNG
-------------
Repository:
  /opt/cocktailbot/source/VERSION

Aktuelle Version:
  2.5

Flutter pubspec:
  version: 2.5.0+25

Für die nächste öffentliche Version VERSION im Repository erhöhen, z. B.:
  2.6

PRÜFUNG
-------
Einstellungen -> Software-Update

Beim Öffnen:
  git fetch origin main
  lokale VERSION lesen
  origin/main:VERSION lesen
  lokalen HEAD-Commit ermitteln
  origin/main-Commit ermitteln

Kein Reset und keine Installation während der Prüfung.

Ergebnisse:
- gleicher Commit: aktuelle Version
- anderer Commit + andere Versionsnummer: neue Version verfügbar
- anderer Commit + gleiche Versionsnummer: neuer Build verfügbar

INSTALLATION
------------
Erst nach Bestätigung:
  fetch origin main
  reset --hard origin/main
  tools/update.sh
  reboot
