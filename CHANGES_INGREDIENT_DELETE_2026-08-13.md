# CocktailBot – Zutaten löschen

- Jede Zutat besitzt jetzt in der Zutatenverwaltung einen Papierkorb-Button.
- Vor dem Löschen erscheint eine Sicherheitsabfrage.
- Wird die Zutat noch in einem Rezept oder einer gespeicherten Cocktailliste verwendet, wird das Löschen blockiert und die Anzahl der Referenzen angezeigt.
- Ist die Zutat nur einer oder mehreren Pumpen zugeordnet, wird beim bestätigten Löschen die Pumpenzuordnung entfernt und die Kalibrierung der betroffenen Pumpe(n) zurückgesetzt.
- Verbrauchsdaten der gelöschten Zutat werden ebenfalls entfernt.
