CocktailBot 2.5 – V38.1 Update-Launcher Fix

Fehlerbild:
  Update konnte nicht gestartet werden:
  Exception: Update-Launcher antwortet nicht

Ursache:
  systemd-run startete einen Type=oneshot-Job ohne --no-block.
  Deshalb wartete der Launcher, während das Backend nach 8 Sekunden abbrach.

Korrektur:
  systemd-run --no-block ...

Damit:
  1. API startet den Launcher.
  2. Launcher legt cocktailbot-self-update.service an.
  3. systemd-run meldet sofort Erfolg zurück.
  4. API antwortet der Flutter-App.
  5. Updatejob läuft unabhängig weiter.
  6. Nach erfolgreichem update.sh erfolgt der Neustart.

Software-Version bleibt:
  2.5
