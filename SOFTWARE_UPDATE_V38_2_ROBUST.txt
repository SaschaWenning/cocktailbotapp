CocktailBot 2.5 – V38.2 robuster Software-Update-Ablauf

1. API startet festen sudo-Launcher.
2. Launcher startet systemd-run --no-block --quiet.
3. Backend erhält sofort eine Startbestätigung.
4. Worker wartet 5 Sekunden.
5. Erst dann: fetch -> reset --hard -> tools/update.sh.
6. Nur nach Erfolg: sync -> 3 Sekunden -> reboot.

Fallback:
Wenn der Launcher trotzdem zu lange braucht oder einen Fehlercode liefert,
prüft das Backend den echten Zustand von cocktailbot-self-update.service.
Läuft der Job, wird der Start als Erfolg gemeldet statt als Timeout-Fehler.

Fehlerlog:
/var/log/cocktailbot-update.log

Version bleibt 2.5.
